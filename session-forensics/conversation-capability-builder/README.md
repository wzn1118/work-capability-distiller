# 对话转能力包

这是一个可脱离当前仓库运行的本地应用。它的唯一任务是：读取任意用户提供的完整或中途对话，识别这段对话真正要解决的问题、需要的输入、每个阶段的产出、用户后来提出的修正，以及最终反复使用的工作流，然后把这些内容生成成可安装的能力包。

## 它具体会生成什么

生成结果不是批量任务列表，也不是固定的“填入任务”页面。每次生成都会根据当前会话产生一份新的 `conversation-ui-blueprint.json`，独立 Agent 首页会直接展示该会话的标题、目的、输入、能力按钮、交付物和修正优先级。

- **Skill**：包含这段对话提炼出的操作流程、输入输出契约、验收标准和恢复规则，可复制到 Codex 的技能目录。
- **MCP**：把会话中实际用到的工具能力封装为标准 MCP 服务，并附配置示例。
- **独立 Agent**：带独立中文 UI、模型接口配置、完整模型列表、当前 Codex 自动连接、工作区权限、文件修改、命令执行、验证、检查点和恢复能力。
- **说明与证据**：能力包内有 `README.md`、`conversation-extraction.json`、`conversation-ui-blueprint.json`、工作流蓝图、完整证据报告和安装脚本。名称会依据会话内容和实际工具自动提取，除非用户在页面中明确修改。

## 新手使用

### Windows

双击 `install-and-start.cmd`。它会把应用复制到当前用户的本地应用目录并打开浏览器；之后可直接运行安装目录里的 `launch.cmd`。

### macOS 或 Linux

在应用目录运行：

```bash
./launch.sh
```

系统要求 Node.js 18 或更高版本，不需要额外的第三方 npm 包。

### 页面内四步

1. 选择 Codex 导出的 `.jsonl`、`.json` 或 `.txt` 文件，或直接粘贴内容。
2. 可选填写兼容 OpenAI 的模型地址、模型名称和临时密钥。密钥只在内存中参与本次请求，不会写入能力包。
3. 点击“读取对话并生成专属预览”，检查标题、目的、首要操作、输入、能力、产出和修正。
4. 必要时修改三个字段，选择 Skill、MCP、独立 Agent，点击生成并下载 ZIP。

## 本地接口

- `GET /api/health`：检查应用是否启动。
- `POST /api/preview`：提交 `{content, ai}`，返回会话专属蓝图和提取结果。
- `POST /api/generate`：提交 `{importId, targets, ai, uiOverrides}`，生成可安装能力包。
- `GET /api/download/<id>`：下载本次生成的 ZIP。

服务默认只监听 `127.0.0.1`。导入文件和生成结果存放在当前用户的本地应用状态目录；模型密钥不会写入这些目录。
