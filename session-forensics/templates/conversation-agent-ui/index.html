一、模型连接

模型在哪里运行？

在线模型通常需要服务地址和 API 密钥。

填写 OpenAI 兼容接口地址，通常以 /v1 结尾。

不知道名称时，保存接口后会自动读取；也可以点击“获取全部模型”。

接口模型全量列表

完整显示接口实际返回的所有模型。搜索只筛选显示，点击模型即可填入模型名称。

尚未读取

保存接口设置后会自动读取；也可以点击“获取全部模型”。

尚未读取接口模型。

密钥只保存在当前服务内存中，不写入能力包，也不会传给本地命令。

模型高级设置

填写完成后，点击“保存并检查连接”。

二、本地工作区与权限

工作区就是允许人工智能查看和操作的项目文件夹。文件工具始终限制在这个文件夹内。

必须填写已经存在的文件夹。保存后，人工智能默认可以浏览目录和读取文本文件。

允许哪些本地操作？
开启命令前请看清：命令虽然从工作区启动，但命令本身可使用绝对路径或调用系统程序。只对你信任的任务开启，并查看对话里的工具执行记录。

默认只允许浏览和读取；写文件和命令需要你主动勾选。

它能直接完成什么

    本地执行能力

    • 浏览与读取列出工作区目录，按行读取 UTF-8 文本文件。
    • 创建与修改获得写入权限后，可创建目录、写文件和精确替换文本。
    • 自动执行命令获得命令权限后，可运行 PowerShell、构建、测试与验证命令。
    • 检索原对话证据按关键词查找原用户消息、助手回应、工具结果、命令和文件变更。
    • 按最新纠正改进后续用户纠正覆盖早期弱要求，同时保留已有工具结果证明有效的做法。
    • 连续自主执行模型会根据每一步结果继续调用工具，直到完成任务或达到步骤上限。
    • 全过程可见界面显示工具名称、参数、执行状态、耗时和结果，不把未执行的操作说成已完成。
