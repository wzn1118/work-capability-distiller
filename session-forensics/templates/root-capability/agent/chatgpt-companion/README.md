# 网页聊天记录伴侣安装说明

这个浏览器伴侣把当前已登录的 ChatGPT、DeepSeek、Gemini 或豆包网页与本机独立 Agent 配对。首次配对后，日常操作全部在主工作台完成：点击对应平台按钮，系统会连续扫描侧边栏、尝试展开“查看全部/加载更多”，逐条显示真实标题和网页地址；打开某条具体对话后，再读取该条完整内容并导入蒸馏。向网页发送任务并取回回答是可选功能。

## 首次安装

1. 保持独立 Agent 工作台页面打开。
2. 在工作台的“读取网页端 AI 聊天记录”区域点击“自动准备浏览器伴侣”。系统会同时打开本文件夹与当前浏览器的扩展管理页，并复制备用连接信息。
3. 在扩展管理页开启“开发者模式”，点击一次“加载已解压的扩展程序”，选择刚刚自动打开的 `chatgpt-companion` 文件夹。
4. 点击浏览器工具栏中的“能力包网页聊天记录伴侣”。它会自动识别当前打开的本机工作台并自动配对，不需要手填地址或配对码。
5. 回到独立 Agent 主工作台，点击 ChatGPT、DeepSeek、Gemini 或豆包按钮打开对应网页并登录，保持标签页打开。

## 自动发现失败时

保持本机工作台页面打开，再点击扩展弹窗中的“自动发现并连接”。只有在本机工作台页面没有打开或浏览器拦截本机连接时，才展开“使用备用连接信息”，粘贴工作台已自动复制的地址与六位配对码。

## 隐私边界

- 不读取、导出或保存 Cookie、账号密码和网页令牌。
- 配对令牌只保存在浏览器扩展本地存储和当前 Agent 进程内存中。
- Agent 服务默认只监听 `127.0.0.1`，局域网和互联网无法直接访问。
- 只有用户从 Agent 页面明确发起的“读取历史对话目录”“读取当前完整对话”或网页任务操作会读取网页内容。
- 历史目录来自所选平台页面的真实侧边栏。系统会滚动虚拟列表并尝试展开页面提供的“查看全部/加载更多”入口；结果同时返回扫描轮数、展开次数、发现数量和是否扫到末尾。网页端没有公开的历史分页入口时，页面本身仍需先加载该部分记录。

各平台网页结构可能更新。页面提示找不到消息、输入框或发送按钮时，先刷新对应平台标签页；若仍失败，请升级能力包中的浏览器伴侣版本。
