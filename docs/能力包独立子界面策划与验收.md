# 能力包独立子界面策划与验收

## 一、页面定位

能力包子界面不是主工作台的结果卡片，也不是文件目录。它是一套可单独使用的“能力控制舱”，负责回答四个问题：

1. 这个能力包解决什么问题。
2. 它从哪些会话、项目、文件和工具中提炼出来。
3. 用户现在可以执行什么任务。
4. 怎样启动 Agent、下载、安装、验证和交给其他用户。

主工作台与能力包子界面只分两层。能力包内部栏目全部在当前子界面切换，不继续打开新的栏目页面。

## 二、视觉方向

采用“精密工作台”而不是普通后台管理页：

- 深色独立顶栏负责返回、位置和状态。
- 白色能力包身份区负责名称、直白说明、主操作和关键指标。
- 横向能力地图负责同页栏目切换。
- 内容区按栏目使用不同信号色，但共享一致的排版、按钮和反馈规则。
- 总览使用深色开始区强调下一步；说明与证据使用高可读白底；Agent 使用深色运行状态区。

颜色只承担信息含义：绿色表示总览和可运行，蓝色表示能力和安装，红褐色表示优先级，灰蓝色表示证据，棕色表示文档阅读。

## 三、页面结构

### 1. 独立顶栏

- 返回主工作台。
- 显示当前能力包和当前栏目。
- 显示“页面已就绪”，不展示主工作台的扫描状态。

### 2. 能力包身份区

- 语义生成的完整包名称。
- 一段直白说明。
- 已完成蒸馏与校验状态。
- 启动 Agent、查看能力、阅读说明、下载 ZIP 四个真实操作。
- 来源会话、原始记录、专属能力、实际工具、校验文件五项指标。

### 3. 能力地图

总览、专属能力、P0-P3、任务目录、项目理解、文件与验证、运行 Agent、安装与接口在同一子界面切换。文件阅读仅在用户打开具体说明或数据时出现。

### 4. 栏目职责

- 总览：只展示用途、开始步骤、命名依据、阶段、工具和交付物。
- 专属能力：展示能力说明和从原会话提炼的完整专长表。
- P0-P3：展示优先原因、执行顺序和证据置信度。
- 任务目录：展示可直接交给 Agent 的任务。
- 项目理解：展示多会话、项目和文件关系。
- 文件与验证：展示证据入口和校验结果。
- 运行 Agent：真实启动、刷新、停止并嵌入独立操作界面。
- 安装与接口：展示 Skill、MCP、Agent、启动器和路径。

## 四、真实使用闭环

1. 用户从主工作台点击能力包，新开独立子界面。
2. 用户在总览确认用途，点击启动 Agent。
3. 页面调用当前能力包的启动接口并展示预检、状态和日志。
4. Agent 成功运行后，操作界面嵌入当前栏目。
5. 用户可以停止或刷新，不需要寻找端口和命令。
6. 用户可以下载 ZIP，交给另一台电脑解压并使用一键启动器。
7. 说明、证据和结构化数据在当前网页转为可读内容，原始技术数据按需展开。

## 五、验收标准

- 主页面与能力包子界面视觉和路由相互独立。
- 子界面顶部始终可以返回主工作台。
- 内部栏目切换不产生新的浏览器页面。
- 任意时刻只有一个内部栏目可见。
- 启动、刷新、停止、下载和说明阅读均连接真实接口。
- 桌面和手机没有横向溢出、按钮遮挡或正文截断。
- 浏览器控制台、页面脚本和必要接口没有错误。
- 使用真实能力包完成一次总览、能力、优先级、Agent、文档和返回流程验收。
