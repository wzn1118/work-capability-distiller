# 主蒸馏台三视图 UI 全量升级方案

## 1. 升级目标

主蒸馏台从“所有功能堆在同一长页面”改为三视图应用。用户一次只完成一个任务：

1. 选择并蒸馏本机对话。
2. 读取并蒸馏网页端对话。
3. 查看建议、证据和能力包结果。

补充来源、包参数、交付物开关和 Windows 换机安装包属于辅助功能，不占用主屏。

## 2. 信息架构

| 导航 | 主屏内容 | 不显示的内容 |
| --- | --- | --- |
| 本机对话 | 工作区、真实会话列表、已选范围、项目上下文、蒸馏按钮 | 网页连接、结果列表、换机安装包 |
| 网页端对话 | 平台连接、历史读取、全量同步、网页会话列表、已选范围、蒸馏按钮 | 本机会话列表、结果列表、换机安装包 |
| 结果 | 蒸馏建议、P0-P3、证据、已生成能力包 | 会话选择、网页连接、换机安装包 |

左侧底部仅保留“更多设置与换机”入口。点击后打开模态窗口，包含：

- 按编号或文件补充会话来源。
- 选择项目文件夹。
- 自定义包名称、包标识和交付内容。
- 生成 Windows 换机安装包。

## 3. 交互规则

- 三个主导航互斥，右侧只渲染当前导航对应的内容。
- 页面地址使用 `section=local|web|results` 保存当前视图，刷新后可恢复。
- 本机和网页端搜索词分别保存，切换页面不会互相污染筛选条件。
- 本机导航显示本机会话总量或已选数量；网页导航显示网页会话总量或已选数量。
- 结果导航显示“待生成”“已解析”“有建议”或“已生成”。
- 智能蒸馏完成后自动进入结果页。
- 能力包生成完成后主工作台停留在结果页，同时按既有流程打开独立能力包子页面。
- 结果页提供“返回选择会话”，不要求用户理解浏览器返回逻辑。
- “更多设置与换机”支持点击关闭按钮、点击遮罩或按 Escape 关闭。

## 4. 视觉与响应式规则

- 桌面端使用 264 像素固定导航栏和单一内容区。
- 主内容最大宽度 1180 像素，避免超宽屏阅读行过长。
- 本机会话页在宽屏并列显示“工作区选择”和“单会话选择”，窄屏自动改为单列。
- 820 像素以下将左侧导航改为顶部三段导航，保留完整功能顺序。
- 390 像素手机宽度不得出现横向滚动、按钮溢出或文字重叠。
- 使用边框、留白和状态色建立层级，不使用装饰性渐变或浮动卡片堆叠。
- 子能力包页面继续使用原有独立页面模式，不显示主蒸馏台导航。

## 5. 功能边界

本次只重构主蒸馏台的信息架构与显示状态，不改变以下既有后端契约：

- 本机 Codex 会话发现与工作区归组。
- 网页端会话连接、持久化、全量同步和断点续读。
- 项目上下文预览。
- 智能蒸馏、P0-P3 和证据生成。
- Skill、MCP、独立 Agent 和能力包生成。
- Windows 换机安装包生成。

## 6. 验收标准

- 本机、网页端、结果三个导航均可直接切换。
- 任意时刻主屏只显示一个导航对应的内容。
- P1 辅助功能和换机安装包不出现在主屏。
- 蒸馏完成自动进入结果页。
- 桌面 1440 x 900 和手机 390 x 844 均无横向溢出。
- 设置窗口内的原有按钮和字段编号保持不变，现有事件绑定继续工作。
- 能力包独立子页面、说明阅读器和 Agent 启动流程不受影响。
- 前端无 JavaScript 语法错误、重复 DOM 编号或浏览器控制台错误。

## 7. 第二轮交互加固

- 三视图切换写入浏览器历史，前进和后退可以恢复对应页面。
- 左侧导航支持方向键、Home 和 End 键切换，鼠标与键盘行为一致。
- 不可见视图同步设置 `hidden`、`inert` 和 `aria-hidden`，避免键盘焦点或读屏进入隐藏内容。
- 结果导航同时读取本轮状态和持久化能力包数量，刷新后不再把已有结果误标为“待生成”。
- 结果页增加能力包搜索和“当前匹配数 / 总数”反馈，可按名称、能力、项目、语义阶段或保存目录查找。
- 没有本轮结果但存在历史能力包时，空状态会明确提示历史能力包数量和下一步入口。

## 8. 第三轮结果中心升级

- 能力包接口由固定前 24 条改为分页返回，响应包含总数和下一页位置。
- 前端按每页 100 条自动续取，用户无需点击“加载更多”即可搜索全部历史能力包。
- 结果筛选分为搜索词、交付物、生成时间和排序四个维度，并提供一键清除。
- 能力包列表默认只展示名称、生成时间、记录数、交付物、两行能力摘要和主要入口。
- 语义阶段、完整目录、ZIP、P0-P3、任务目录和说明入口放进逐项展开区，减少重复信息占用屏幕。
- 每个展开按钮提供 `aria-expanded` 和 `aria-controls`，展开状态可被辅助技术识别。
